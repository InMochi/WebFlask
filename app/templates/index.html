Selamat datang di WebFlask

Homepage sederhana dengan struktur proyek Flask yang rapi: Application Factory, Blueprint, Jinja2 template inheritance, serta stylesheet dan header keamanan terpisah.

Lihat Fitur Struktur Proyek

Fondasi Utama

Struktur Modular

Logika aplikasi dipisah ke dalam paket app/ menggunakan pola create_app() dan Blueprint agar mudah dikembangkan.

Template Terstruktur

HTML dikelola melalui base.html dan index.html dengan auto-escaping bawaan Jinja2 tanpa HTML inline di Python.

Keamanan Default

Aset statis disajikan lokal tanpa inline script/style, dilengkapi header CSP, X-Frame-Options, dan X-Content-Type-Options.

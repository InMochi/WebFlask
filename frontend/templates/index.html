Flask 3 Starter

Selamat datang di WebFlask

Homepage sederhana dengan pemisahan folder backend (Python/API) dan frontend (Jinja2 templates & static assets) dalam satu server Flask yang rapi dan aman.

Lihat Fitur Struktur Proyek

Fondasi Utama

Backend & Frontend Terpisah

Logika server dan JSON API berada di backend/, sedangkan template HTML dan aset CSS dikelola terpisah di frontend/.

Template Terstruktur

HTML dikelola melalui base.html dan index.html dengan auto-escaping bawaan Jinja2 tanpa HTML inline di Python.

Keamanan Default

Aset statis disajikan lokal tanpa inline script/style, dilengkapi header CSP, X-Frame-Options, dan X-Content-Type-Options.
